TetrisLite is a Tetris game written in Kotlin Multiplatform, with Compose Multiplatform for Android, desktop, and the web, and SwiftUI for iOS and macOS.

The project showcases multi-module architecture while exploring how shared Kotlin foundations work with different user-interface technologies. Its repository remains available as an archived open-source project.
